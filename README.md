# my gaming tracker

Простой веб-трекер для отслеживания статуса прохождения компьютерных игр. Проект написан на фреймворке Laravel с использованием Eloquent ORM и контейнеризирован с помощью Docker.

## Технологический стек
* **Фреймворк:** Laravel (PHP 8.2)
* **Веб-сервер:** Nginx
* **База данных:** PostgreSQL (Eloquent ORM)
* **Окружение:** Docker + Docker Compose

## Функционал
* Полный CRUD для управления списком игр (добавление, просмотр, редактирование, удаление).
* Фильтрация игр по статусу прохождения.
* Постраничная пагинация списка игр.
* Система авторизации пользователей и регистрация новых аккаунтов через встроенный Laravel Auth с хэшированием паролей.
* Безопасное удаление профиля пользователя со всеми связанными данными из БД.

## Локальный запуск через Docker

Требуется установленный Docker Desktop.

1. Клонируйте репозиторий и перейдите в папку проекта:
   ```bash
   git clone https://github.com
   cd laravel-my-gaming-tracker
   ```

2. Скопируйте файл `.env.example` и переименуйте его в `.env`.
   Откройте `.env` и впишите туда свой логин и пароль от PostgreSQL (или логин postgres и пароль secret_pass).
   Сохраните изменения в файле.

3. Запустите контейнеры командой:
   ```bash
   docker compose up -d --build
   ```

4. Сгенерируйте уникальный ключ приложения и накатите миграции вместе с тестовыми данными (сидерами):
   ```bash
   docker compose exec app php artisan key:generate
   docker compose exec app php artisan migrate --seed
   ```

5. Откройте браузер и перейдите по ссылке: `http://localhost:8080`.

Для остановки проекта используйте команду:
```bash
docker compose down
```
**Примечание по БД:** База данных PostgreSQL полностью изолирована и разворачивается автоматически внутри Docker-контейнера. Для входа под тестовым аккаунтом используйте: `test_user` / `password123`.
